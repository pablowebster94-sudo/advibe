# AdVibe Visual Flow

MVP de estudio creativo de AdVibe.

## Ruta

`/visual-flow`

## Flujo

1. Intérprete: convierte el pedido en brief estructurado.
2. Director de Arte: convierte el brief en prompt técnico.
3. Estudio: queda preparado para conectar un proveedor de generación de imágenes.
4. Control de Calidad: revisa marca, formato, jerarquía y separación del texto.

## Integraciones previstas

- OpenAI: interpretación, dirección de arte y generación de imagen.
- Supabase: clientes, campañas, piezas y generaciones.
- Bannerbear: ensamblaje final.
- Canva: exportación/plantillas, sujeto a credenciales y API disponible.

El MVP muestra una composición demo cuando no hay proveedor configurado. No debe presentarse como generación real.
