# VentAds Android

Native Android wrapper for the existing VentAds web application.

The APK loads the configured VentAds HTTPS URL through Capacitor; the existing web app is not duplicated.

Default URL:
https://id-preview--d77c7bc9-c09c-4000-a642-467b377d8d6e.lovable.app

The GitHub Actions workflow also accepts another HTTPS deployment URL through workflow_dispatch.
